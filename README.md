# DhanaSree PCB Solutions — Landing Page

A modern, responsive landing page built with React (Vite) + Tailwind CSS and Framer Motion for animations. Designed to promote PCB design training & services.

## Features
- Hero, About, Tools, Courses, Why Choose Us, Contact sections
- Responsive, mobile-first design
- Tailwind CSS utilities and custom PCB-themed background
- Framer Motion animations
- Sticky navbar with scroll spy & smooth scroll
- Click-to-call, mailto, WhatsApp links
- Reusable React functional components

## Setup
1. Install dependencies:
   npm install

2. Start dev server:
   npm run dev

3. Build for production:
   npm run build

## Notes
- Contact form is a demo (no backend). Hook to your preferred form handling or email service.
- Replace placeholders (map, social links) with real details when deploying.
